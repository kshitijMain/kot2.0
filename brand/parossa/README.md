# Parossa brand assets

The mark: a serving ladle seen from above (parosna, "to serve") that also reads as a "P".
Teal ring and handle, saffron dish.

Colours
- Teal #0F766E (primary), deep teal #134E4A (wordmark), light teal #2DD4BF (on dark backgrounds)
- Saffron #F7931E (accent; decoration only, not for small text on white)
- Off-white #FAF7F2 (icon and page background)

Files
- parossa-logo.svg / .png        horizontal logo for light backgrounds
- parossa-logo-on-dark.svg       for dark backgrounds
- parossa-mark.svg / .png        the symbol alone; parossa-mark-mono.svg one colour
- favicon.svg                    browser tab icon
- icon.png, android-icon-*.png, splash-icon.png   drop-in replacements for
  apps/waiter-app/assets and apps/table-tablet/assets (same names, 1024 x 1024)

Wordmark letters are outlines from Inter Display SemiBold (SIL Open Font License).
