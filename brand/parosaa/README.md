# Parosaa brand assets

Clean vector redraws of the two source images in `source/`. `comparison.png` shows them side by
side.

Colours: deep ink `#20223D`, gold `#F5A623` (the P), saffron `#E8821E` (the dot), warm cream
`#FBF7F0` (wordmark on dark).

| File                                       | Use                                              |
| ------------------------------------------ | ------------------------------------------------ |
| `icon.svg`, `icon.png` (1024)              | The app icon: gold P and saffron dot on deep ink |
| `wordmark.svg`, `.png`                     | The name on light backgrounds                    |
| `wordmark-on-dark.svg`, `.png`             | The name on dark surfaces (cream letters)        |
| `mark-mono.svg`, `.png`                    | The P and dot in one colour                      |
| `favicon.svg`, `favicon-32.png`, `-16.png` | Browser tabs                                     |
| `android-icon-*.svg`, `.png` (1024)        | Android adaptive icon layers                     |
| `splash-icon.svg`, `.png` (1024)           | The Android splash screen                        |
| `play-store-icon.png` (512)                | The Play Store listing (full bleed, no alpha)    |
