# Onboarding material

Files the vendor gives a restaurant during onboarding (BRD §7, ONB).

- `menu-template.xlsx`: the menu import template (ONB-005). It has sheets Items, Variants,
  Modifiers and Combos, each with a header row and a notes row saying what goes in each column.
  It is generated by `pnpm --filter @rp/server build && pnpm --filter @rp/server menu:template`.
  It is also `menu.xlsx` inside the menu file below.

## The menu file

A menu is managed only in the manager dashboard on the restaurant's own PC; it needs no internet,
no Control Plane and no licence (decided 2026-10-25). Two ways, side by side on set-up step 7:

- **By hand**: Manage → Menu → "Add a dish".
- **The menu file**: one .zip holding `menu.xlsx` (the template above), a `photos/` folder and a
  short README. Photos are named after the dish's short code (`PT01.jpg`) or its exact name
  (`Paneer Tikka.jpg`), matched as "Add photos in bulk" matches them.
  1. Manage → Menu → "Load menu file" → "Download empty menu file".
  2. Fill `menu.xlsx` and put the photos in `photos/` on any computer; zip the folder again. A
     plain `menu.xlsx` also loads, for a menu without photos.
  3. "Load menu file": the PC checks it (every problem by sheet, row and column), then shows every
     dish with its photo. The manager maps the file's tax group and kitchen station names to the
     ones set up on this PC (tax rates are never in the file), corrects any photo match, and adds
     it. Nothing is saved before that, and it is saved as a **draft**.
  4. Publish (Manage → Menu → "Publish menu"): the menu check and the publish step, as for any
     change. Nothing reaches the devices before.

"Export menu file" (Manage → Menu) saves the menu with its photos as the same zip. The onboarding
team prepares a restaurant's menu on its own test PC, exports it, and loads it at the restaurant
(from a USB stick); it is also a simple copy of the menu. A file is refused, with the reason, when
it is larger than 100 MB, holds a path pointing outside it, holds anything but the sheet, a README
and photos, or a photo that is not a JPEG, PNG, WebP or HEIF image.

Photos added later: "Add photos in bulk" takes many photos at once, or a whole folder ("Choose a
folder"), matched by short code or name; the POS, the waiter app, the table tablet and the QR menu
show them, and a plain placeholder for a dish without one.

Menus are not read from photos by AI: that feature is switched off and shown on no screen (its
server and Control Plane code stay in place, unused).
